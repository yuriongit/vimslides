# AGENTS.md

## Project

VimSlides is a keyboard-first web presentation editor. Slides are free-form boxes on a canvas
edited through Vim modal editing (modes, scopes, motions, ex commands).

Read `docs/PRD.md` before making product or editor decisions.

## Stack

- TypeScript, React 19, Vite, Tailwind CSS v4, shadcn/ui, TanStack Router/Start, Supabase.

## Commands

The scripts are already defined in `package.json` and are run with bun:

- `bun run dev` — dev server (port 3000)
- `bun run build` — production build
- `bun run preview` — preview production build
- `bun run generate-routes` — regenerate TanStack route tree
- `bun run format` — Biome format
- `bun run format:w` — Biome format --write
- `bun run lint` — Biome lint
- `bun run lint:w` — Biome lint --write
- `bun run check` — Biome check
- `bun run check:w` — Biome check --write

## Project structure

- `src/routes/` — TanStack Start file-based routes (`__root.tsx`, `_public/`, `_authenticated/`)
- `src/components/` — `custom/` (app-specific), `ui/` (shadcn), auth forms, `ballmac/` (registry blocks)
- `src/lib/` — Supabase client, utils, safe-next-path
- `src/routeTree.gen.ts` — generated by TanStack Router; do not edit manually
- `src/index.css` — Tailwind v4 + shadcn theme tokens, Catppuccin light/dark palettes, fonts
- `supabase/` — local Supabase configuration

## Standards

- Biome is the formatter and linter of record (`biome.json`).
- Import alias is `@/*`, mapped to `./src/*`.
- TypeScript is strict; `verbatimModuleSyntax`, `noUnusedLocals`, `noUnusedParameters`, and
  `noFallthroughCasesInSwitch` are enabled.

## Ignored files

- Do not read, create, or commit files matched by `.gitignore` (e.g. `.env`, `.env.local`,
  `node_modules`, `dist`, `*.local`, `.tanstack`).

## Before committing

- Run `bun run check:w` (Biome check --write) before committing.
- Indentation does not need to be handled manually; Biome handles formatting via `check:w`.
